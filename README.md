# Pickwise

**사용자의 선택 기준에 따른 맞춤형 의사결정 솔루션**

여러 결정을 앞둔 **사회초년생**이 정보는 충분한데 "나에게 중요한 기준"이 정리되지 않아 결정을 못 내릴 때,
기준과 중요도를 정리하고 선택지를 비교해 **왜 이 선택이 나은지**까지 보여주는 웹앱입니다.

- 배포 주소: **https://pickwisever1.vercel.app**

## 이용 흐름
1. 결정 입력 — 고민 주제와 선택지(A/B, 최대 4개)
2. 기준 선택 — 공통 기준(비용·시간·만족도) + 고민 분류별 기준 고르기 + 기준 직접 추가
   - 분류: 주거 · 소비 · 여가 · 자기계발 · 금융생활 · 기타
3. 중요도 설정 — 기준마다 0~100 슬라이더, 비중(%)은 자동 계산
4. 정보 입력 — 설명글을 쓰면 기준별 점수(0~100)를 자동 제안, 별로 직접 수정
   - "예시로 체험하기": 데이터팀이 공개 자료로 만든 8개 시나리오 (일부 시연용 추정값 포함)
5. 분석 결과 — 종합 점수, 항목별 그래프, 가장 큰 차이, 한 줄 요약, 민감도 분석
6. 다음 결정 추천 — 이어서 고민할 것 + 새 결정 시작

## 실행 방법
- 배포 주소로 접속하거나, 저장소를 내려받아 `index.html`을 더블클릭하면 바로 실행됩니다. (설치·빌드 불필요)
- 입력한 결정 기록은 사용 중인 브라우저에만 저장되며, 서버로 전송되지 않습니다.

## 기술
- HTML / CSS / JavaScript (프레임워크 없음)
- 고정 데이터: `data/` 폴더
- 배포: Vercel (정적 사이트)
